1. 什么是 Streamlit？

Streamlit 是一个 Python Web 应用开发框架，可以把 Python 程序快速变成网页。
传统开发网页需要：
HTML + CSS + JavaScript
而 Streamlit：
import streamlit as st
st.title("我的网页")
几行 Python 就能生成网页。
简单理解：
Python代码
    ↓
Streamlit
    ↓
网页界面
---

3. 如何安装 Streamlit？
在终端输入：
pip install streamlit
如果使用 Conda 环境：
conda activate ai
pip install streamlit
查看是否安装成功：
streamlit --version
如果显示版本号说明安装成功。
---
4. Streamlit 运行命令是什么？
假设文件名为：
app.py
运行：
streamlit run app.py
例如：
(ai) D:\ai> streamlit run app.py
运行后浏览器会自动打开网页。
---
5. st.title() 作用是什么？
用于显示网页标题。
代码：
import streamlit as st
st.title("AI聊天机器人")
效果：
AI聊天机器人
============
相当于网页的大标题。
---
6. st.write() 作用是什么？
用于在网页输出内容。
代码：
st.write("你好")
显示：
你好
类似于：
print("你好")
区别：
print() → 终端输出
st.write() → 网页输出
---
7. st.text_input() 作用是什么？
用于创建输入框。
代码：
name = st.text_input("请输入名字")
效果：
请输入名字
[___________]
用户输入：
张三
变量：
name
就会保存：
"张三"
---
8. st.button() 作用是什么？
用于创建按钮。
代码：
if st.button("提交"):
    st.write("提交成功")
效果：
[提交]
点击后显示：
提交成功
常用于：
登录
注册
发送消息
提交表单
---

1. 什么是 WebUI？
WebUI（Web User Interface）意思是：
Web = 网页
UI = 用户界面
即：
通过浏览器访问和操作的软件界面。
例如：
[ChatGPT](https://chatgpt.com?utm_source=chatgpt.com)
[百度](https://www.baidu.com?utm_source=chatgpt.com)
[GitHub](https://github.com?utm_source=chatgpt.com)
[淘宝](https://www.taobao.com?utm_source=chatgpt.com)
这些都是 WebUI。
简单理解：
浏览器打开
    ↓
看到按钮、输入框、图片
    ↓
进行操作
这就是 WebUI。

3. 网页和命令行有什么区别？
对比项	网页(WebUI)	命令行(CLI)
操作方式	点击按钮	输入命令
用户群体	普通用户	开发人员
学习难度	低	较高
界面	图形化	纯文字
美观程度	高	一般
开发速度	略慢	快
---
命令行示例

print("你好", name)
运行：
请输入名字：张三
你好 张三
---
WebUI示例
请输入名字
[________]
[提交]
你好 张三
功能一样。
但网页更友好。

1. 什么是前端（Frontend）？
前端就是：
用户能够直接看到和操作的部分。
例如你打开一个网页：
┌─────────────────┐
│ AI聊天机器人     │
├─────────────────┤
│ 输入问题：       │
│ [___________]   │
│                 │
│ [发送]          │
└─────────────────┘
这些内容：
标题
输入框
按钮
图片
表格
聊天界面
都属于前端。
简单理解：
用户看得见
用户点得到
用户能操作
        ↓
       前端
---
2. 什么是后端（Backend）？
后端就是：
处理业务逻辑和数据的部分。
用户通常看不到。
例如：
用户输入：
"你好"
      ↓
发送到服务器
      ↓
调用AI模型
      ↓
生成回答
      ↓
返回结果
这部分工作属于后端。
后端常见工作：
API调用
数据库操作
用户登录验证
AI模型推理
文件处理
例如：
response = client.chat.completions.create(
    model="deepseek-chat",
    messages=messages
)
这就是后端逻辑。
---
3. 按钮属于前端还是后端？
按钮属于：
前端
例如：
st.button("发送")
网页显示：
[发送]
用户能看到并点击。
所以属于前端。
---
但是：
if st.button("发送"):
    调用AI()
这里：
按钮本身
    ↓
前端
点击后执行的逻辑
    ↓
后端
要区分清楚。
---
4. API调用属于前端还是后端？
属于：
后端
例如：
import requests
response = requests.post(
    url,
    headers=headers,
    json=data
)
或者：
from openai import OpenAI
client = OpenAI(
    api_key=API_KEY,
    base_url="https://api.deepseek.com"
)
这些都属于后端。
因为：
用户看不到
负责处理数据
与服务器通信
所以是后端工作。
---
