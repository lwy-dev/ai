Day5 最重要的 5 道答辩题
老师或评委最喜欢问：
① 为什么AI能记住前面说的话？
答：
AI本身不会记忆。 程序把历史聊天记录保存到messages中， 每次请求时一起发送给模型， 所以模型能够根据上下文回答问题。
② messages是什么？
答：
messages是聊天记录列表， 里面保存system、user、assistant消息。
③ 为什么要用POST？
答：
因为需要向服务器提交问题和历史记录， 所以使用POST请求。
④ API Key有什么作用？
答：
API Key用于身份认证， 证明当前用户有权限调用模型服务。
⑤ 聊天机器人核心流程是什么？
答：
用户输入 → 保存历史 → 调用API → 模型生成回答 → 输出结果 → 保存回答 → 继续聊天
